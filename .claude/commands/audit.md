Проведи проверку: $ARGUMENTS

Передай подагенту `reviewer` изменения (по умолчанию `git diff main...HEAD`) и попроси проверить их по чек-листу из его описания. Результат выведи таблицей: № · файл:строка · нарушение · инвариант · тяжесть (блокер / важно / замечание) · предложение.

Ничего не исправляй сам. Блокеры предложи оформить задачами через `/task`.
