Решение: $ARGUMENTS

1. Сформулируй запись в формате `docs/core/DECISIONS.md`: **Решение / Почему / Что меняет / Отменяет**. Номер — следующий свободный П.
2. Перечисли документы и файлы, которые нужно изменить (CLAUDE.md, ROADMAP, GLOSSARY, конфигурация, код), и сами правки.
3. Если решение отменяет прежнее — пометь прежнее ссылкой «отменено П…», текст не удаляй.
4. Текст решения — комментарием в PR (`gh pr comment N --body-file …`), владельцу — только вопрос. После «да» внеси запись и правки, запусти `npm test`.
