Начинаем сессию работы над agentic-buyer-app.

1. Прочитай `CLAUDE.md`, затем `docs/core/STATUS.md` (раздел «Следующая сессия»), затем `docs/core/ROADMAP.md`.
2. Проверь рабочее состояние: `git status`, `git rev-parse --abbrev-ref HEAD`, `git log --oneline -5`. Если есть незакоммиченные изменения — назови их и спроси, что с ними делать.
3. Запусти `npm test` (если `node_modules` нет — попроси разрешения на `npm install`). Запиши результат. Затем — `npm audit --audit-level=high` **без** конфигурации исключений (не `audit-ci`): это проверка срока исключения `GHSA-fc5q-39xc-vjpf` в аудите CI (К3.1а, передача #21, РП79; строка в STATUS «Открыто»). Зелёный вывод — признак снятия: предложи владельцу убрать `audit-ci` из `package.json`, удалить `audit-ci.json`, вернуть шаг CI к `npm audit --audit-level=high` и снять строку STATUS. Красный — исключение ещё нужно, назови число записей `high`.
4. Сверь план сессии с фактом: всё ли из предыдущей сессии сделано, нет ли новых записей в «Расхождениях».
5. Выведи коротко:
   - этап и номер сессии;
   - задачи сессии с оценкой времени;
   - контрольные точки;
   - что ты прочитаешь для первой задачи: экран холста, требования ядра (`agentic-buyer-ref`, SPEC и инварианты), решения П.
6. Жди «да» владельца. До «да» ничего не меняй.
