# agentic-buyer-app

Приложение с экранами сделки через агента покупателя: человек видит, что агент
делает в пределах мандата, а решения, которые принадлежат человеку, остаются
у человека.

Приложение **не исполняет платёж само и не проверяет полномочия само**. Ядро
исполнения — пакет [`agentic-buyer-ref`](https://github.com/kuzin4u/agentic-buyer-ref)
(детерминированное, без языковой модели); приложение показывает человеку, что
делает ядро, и передаёт человеку решения, которые ядро ему передаёт. Платёжные
реквизиты приложению недоступны: на экране и в журнале — только идентификаторы
(`order_id`, `mandate_id`, `instrument_token`).

Интерфейс — на русском и английском. Название, цвета и логотип банка задаются
настройкой (`config/brand.*.json`), в коде литералом не пишутся.

## Что здесь есть сейчас

- **Демо-стенд** (`npm run demo`, `src/demo/`): настоящий агент и стенд Платформы
  `agentic-ps-platform` на 127.0.0.1, монитор операций, сюжеты сделки.
- **Пульт DEMO-2** и дашборды (`src/pult/`, `src/dashboards/`): ход сделки по
  стадиям, вердикты по справочнику правил, интерпретация причин, журнал действий
  и акт приёмки ACC-1.

**Демо-стенд, дашборды и пульт — тестовый интерфейс** (решение П2): они нужны,
чтобы проверять поведение агента и Платформы на живых сюжетах, и не являются
экранами, которые увидит покупатель. Экраны сделки по макетам (агент, мандаты,
кабинет продавца, выгода, подтверждение passkey) — следующие этапы.

## Запуск

Node ≥ 20.19.

```
npm ci
npm test        # тесты
npm run check   # проверка типов и ESLint
npm run demo    # демо-стенд на 127.0.0.1
```

Зависимости `agentic-buyer-ref` и `agentic-ps-platform` ставятся по `git+https`
из репозиториев проекта; для доступа к ним нужен токен чтения.
