### П2. Демо-стенд: состав и границы
- **Решение:**

  - **Решение:** к п. 1–2. ### П5. Эмулятор клиента «Авто» — только при прогоне тестов пульта
- **Решение:**
  1. Режим «Решения людей» у пульта: «Вручную» и «Авто». «Вручную» — по умолчанию. Режим «Авто» (эмулятор клиента) существует **только при `DEMO_FAULTS=1`**: стенд `createStand({ demo: { faults: true } })`, прогон 25 тестов задания (`docs/reference/2026-11-07-zadanie-testirovanie-pulta-v1.0.xlsx`).
  2. В режиме «Авто» эмулятор клиента:
     - подписывает поручение и корзину на стенде (`issuer.sign`);
     - подтверждает запрос выше порога (`issuer.confirm`);
     - отказывается от корзины, если этого требует сюжет (П-03).

     Решение он принимает по сценарию теста, а не по ответу ядра.
  3. **Пометка — везде.** Каждое действие эмулятора помечено «эмулятор клиента» / «client emulator»:
     - на шине: источник `client-emulator`;
     - в журнале пульта;
     - в таблице тестирования;
     - в акте ACC-1.

     Пока включено «Авто», на пульте горит строка «эмулятор клиента: авто».
  4. **Без режима сбоев «Авто» нет — ни кнопки, ни кода.** Это показ людям (`{ actions: true }`), песочница ACC-2 и пилот:
     - модуль эмулятора не создаётся;
     - кнопки нет;
     - маршрут действия отвечает 404.
  5. **Граница.** `issuer.sign` и `issuer.confirm` вызывает только модуль сборки демо-стенда: `src/demo/client-emulator.ts` и автотесты. Тест графа импортов проверяет, что код пульта (`src/pult/`, `src/demo/public/pult/`) не импортирует ни эти вызовы, ни модуль эмулятора. Пульт только передаёт команду «включить / выключить авто» через порт.
  6. Пять сюжетов ACC-1 и тесты У-01…У-04 владелец проходит в режиме «Вручную»: подписывает на экране мандатов банка, вводит код на странице УПК.
- **Почему:** 25 тестов задания прогоняются после каждого кирпича ревью П-11. Каждый полный прогон руками — ≈ 1–1,5 ч владельца. Модель 1.23 даёт режим «Решения людей: Авто», но на настоящем стенде это подпись и подтверждение за клиента, а их запрещают П2 п. 5 и инвариант 3. Поэтому режим ограничен прогоном тестов на стенде с эмуляторами, помечен везде и отделён границей импортов. Показ людям и приёмка ACC-1 остаются за человеком.
- **Отклонено:** (б) — все 25 тестов руками.
- **Что меняет:**
  - П2 п. 5 — пометка «уточнено П5». Слова «`issuer.sign` и `issuer.confirm` — только в автотестах» дополняются: «и в эмуляторе клиента при `DEMO_FAULTS=1` (П5)». Текст п. 5 не удаляется;
  - CLAUDE.md, инвариант 3 — дописывается: «Исключение — эмулятор клиента демо-стенда в режиме прогона тестов (`DEMO_FAULTS=1`), помеченный на шине, в журнале и в акте (П5)»;
