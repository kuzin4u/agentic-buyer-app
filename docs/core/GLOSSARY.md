# Термины

Полный словарь — в ядре (`agentic-buyer-ref`, `docs/core/GLOSSARY.md`). Здесь — термины экранов и их названия в интерфейсе на английском (русские — как в первом столбце).

| Термин | В интерфейсе | Значение |
|---|---|---|
| Агент | Agent | Программа, действующая по поручению клиента в пределах мандата |
| Мандат намерения | Mandate | Задача и пределы: предмет, сумма, срок, категории |
| Мандат корзины | Cart approval | Согласованные состав и стоимость заказа |
| Порог подтверждения | Confirmation threshold | Сумма, выше которой покупку подтверждает человек в банке |
| Контур гарантий | Covered by payment system guarantees | Продавцы, у которых оплата идёт с признаком агентской операции |
| Вне контура | Not covered | Предложения, по которым агент не платит, а передаёт ссылку |
| Экран выгоды | Savings screen | UI-К4: что человек получил от сделки через агента (решение К3) |
| Пульт | Console | Пульт DEMO-2 по модели 1.23: Ход, Контроль, Интерпретатор, Журнал — на шине демо-стенда (Р-1318, Р-1426) |
| Эмулятор клиента | Client emulator | Модуль сборки демо-стенда, который в режиме «Авто» подписывает поручение и корзину и подтверждает запрос за клиента; только при `DEMO_FAULTS=1`, каждое действие помечено (П5) |
| Решения людей: Авто / Вручную | Human decisions: Auto / Manual | Режим пульта: «Вручную» — решения клиента принимает человек на экране мандатов банка и странице УПК (по умолчанию); «Авто» — эмулятор клиента, только при прогоне тестов (П5) |
| На стенде не проверяется | Not checked on the stand | Статус правила справочника 89, которое пульт на стенде не проверяет; не «норма» (Р-1426) |
| en — после MVP | en — after MVP | Пометка правила справочника 89 без английского текста (П6) |
| Драйвер нарушителя (ПР) | Violator driver (ПР) | Модуль сборки демо-стенда, который разыгрывает нарушения агента вида «ПР» (Н-01, Н-05 ПР, Н-06…Н-09) ключом агента приложения и помечает каждое на стенде (`stand.demo.mark`); только при `DEMO_FAULTS=1` (П7) |
