Сессия — около 3 часов работы в Claude Code. Оценки предварительные и уточняются по факту в `/finish`.

## Цель

Приложение с экранами сделки через агента покупателя на ядре `agentic-buyer-ref`: человек видит, что агент делает в пределах мандата, а решения, которые принадлежат человеку, остаются у человека. Два плана рынков (решение владельца 14.10.2026):

- **«Россия»** — совместный план с Платформой ПС и agentic-core: `agentic-buyer-ref/docs/reference/joint-plan.md`;
- **«Запад»** — `agentic-buyer-ref/docs/reference/plan-west.md` (копия появится после К4.1 служебной сессии agentic-buyer-ref).

Интерфейс — на русском и английском, бренд банка (название, цвета, логотип) — настройкой. Макеты — холст «Экраны сделки через агента» (claude.ai, 13.10.2026).

## Порядок внутри этапов

- Экран строится по макету холста; данные — только из ядра (инварианты 2, 6 CLAUDE.md). Пока у ядра нет нужной функции (клиент мандатов — AG-05, пакет оплаты — AG-11, события — AG-06), экран работает на демонстрационном источнике данных за тем же портом, с пометкой в STATUS «Открыто»; приложение не подменяет решения ядра.
- Каждый экран закрывается тестом состояний (что показано, какие действия доступны) на обоих языках.
- Ядро подключается по тегу `agentic-buyer-ref` (`git+https`), когда тег появится.
