Проект Agentic Commerce · приложение `agentic-buyer-app` · окно А · сессия 19 · версия 1.0

## Функционал задачи, простыми словами

Перед тем как окно Б начнёт строить экраны (ИН-0), у обоих окон должен быть один общий договор: какие запросы шлёт экран, что отвечает сервер приложения, как выглядят деньги, ошибки и состояние покупки. КТ-0 превращает документ К-Б в код: типы, таблицу «состояние ядра → шаг экрана», хэш показанного и тесты. Тогда окно Б пишет экраны против проверенных типов, а не против текста.
